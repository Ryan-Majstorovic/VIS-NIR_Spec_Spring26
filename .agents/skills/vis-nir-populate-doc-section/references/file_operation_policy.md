# File Operation Policy

## Before Any Destructive Operation

Show a file-operation plan before moving, renaming, deleting, or overwriting files.

## Plan Contents

Include:

1. files to create
2. files to modify
3. files to move or rename
4. files or sections proposed for deletion
5. rationale for each operation
6. risk level for each operation
7. preservation strategy for incomplete or partial docs
8. rollback recommendation

## Apply Rules

- Do not perform destructive operations without explicit user approval.
- Keep the `apply` manifest aligned with the approved plan.
- Treat unapproved destructive operations as blocked.
