# Research Workflow

## Purpose

Use this skill to populate or revise an existing VIS-NIR documentation section after the section structure already exists.

If the target section does not exist yet, stop and use `$vis-nir-add-doc-section` first.

## Ordered Flow

1. Confirm the target section and requested topic.
2. Run the `inspect` script to assemble a source inventory and host-readable findings.
3. Read live evidence from:
   - current docs
   - repo code
   - historical DOCX and PPTX files
   - required PDFs through the PDF MCP
   - required VSDX files through the Visio MCP
4. Return the research brief.
5. Ask Round 1 clarifying questions.
6. Ask Round 2 clarifying questions after the user replies.
7. Confirm the exact location inside `docs/source`.
8. Build the draft manifest.
9. Show the file-operation plan.
10. Apply only the approved changes.

## Required Brief Sections

- files and folders inspected
- current documentation findings
- implementation findings
- historical-source findings
- preferred-reference findings
- structure rules that apply
- discrepancies and uncertainties
- missing references
- incomplete documentation needing reconstruction
