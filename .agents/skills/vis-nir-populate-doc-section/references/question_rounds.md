# Question Rounds

## Round 1

Ask Round 1 after the initial research brief.

Cover:

1. documentation destination inside `docs/source`
2. intended section scope
3. discrepancies between docs and implementation
4. ambiguous subsystem behavior
5. treatment of incomplete existing documentation
6. requested external or internal references

## Round 2

Ask Round 2 after the user answers Round 1.

Cover:

1. final confirmation of documentation placement
2. final confirmation of section boundaries
3. final confirmation of terminology
4. final confirmation of reference sources
5. final confirmation of planned versus implemented labeling
6. final confirmation of any move, rename, delete, or migration proposal

## Absolute Gate

The documentation location inside `docs/source` must always be confirmed before writing, even when the user supplied a destination path in the original request.
