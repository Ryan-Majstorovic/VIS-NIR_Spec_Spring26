Data Flow
=========

Layer 2 functionality table of contents for end-to-end measurement and control
flow.

The measurement plane carries detector data toward display, capture, retention,
and export.  The control plane carries connection, start, stop, and
integration-time requests toward Embedded and returns outcomes/status.
