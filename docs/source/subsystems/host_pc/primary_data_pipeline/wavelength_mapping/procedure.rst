Ordered Mapping Behavior
------------------------

UUID: :ref:`4457507B-E80D-4B0E-872F-6586B689197E <uuid-4457507b-e80d-4b0e-872f-6586b689197e>`

1. Receive ordered effective-pixel positions and corrected detector values.
2. Load the approved pixel-to-wavelength map.
3. Associate one wavelength with each effective detector position.
4. Evaluate intended coverage against the 400-1000 nm target.
5. Retain known-reference residual evidence for validation.
