Ordered Record Assembly
-----------------------

UUID: :ref:`8FDD28F1-294F-444C-A80C-6922B293F7A8 <uuid-8fdd28f1-294f-444c-a80c-6922b293f7a8>`

1. Associate raw ADC counts, processed counts, wavelengths, volts, and processed intensity with the same source measurement.
2. Preserve raw ADC counts independently of later derived values.
3. Mark the record ready only when required data products remain aligned.
4. Provide the record to visualization, retention, and export initiation.
