Export Workflow
---------------

UUID: :ref:`8F895FC9-CC7E-4E8B-8D84-31FD5160BED6 <uuid-8f895fc9-cc7e-4e8b-8d84-31fd5160bed6>`

1. Accept an export request for a retained acquisition session.
2. Confirm that exportable records contain the five required aligned data products.
3. Create CSV output containing raw ADC counts, processed counts, wavelength, volts, and processed intensity.
4. Report success or failure without discarding retained data needed for review.
5. Keep the session available according to the approved retention policy.
