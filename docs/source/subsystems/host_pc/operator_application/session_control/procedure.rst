Operator Workflow
-----------------

UUID: :ref:`2BEA17D8-4452-4E29-8EB3-32FAACB92673 <uuid-2bea17d8-4452-4e29-8eb3-32faacb92673>`

1. Connect and establish readiness before acquisition controls are enabled.
2. Start an acquisition session and present its current status.
3. Allow inspection of accepted processed data during the operator session.
4. Stop or pause only according to the approved acquisition policy.
5. Retain eligible data for export and disconnect safely.

.. _uuid-343ec28f-8f38-4a41-9d8e-41d012468040:

Workflow Conditions
-------------------

UUID: :ref:`343EC28F-8F38-4A41-9D8E-41D012468040 <uuid-343ec28f-8f38-4a41-9d8e-41d012468040>`

Actions unavailable in the current state remain gated. Session identity, pause semantics, resume, disconnect recovery, and setup-time acceptance are Not In Docs.
