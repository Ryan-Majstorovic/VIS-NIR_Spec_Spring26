Selection And Recall Workflow
-----------------------------

UUID: :ref:`35073708-A6CA-4FF8-9F4A-7E69F6712B54 <uuid-35073708-a6ca-4ff8-9f4a-7e69f6712b54>`

1. Present available bias/dark, wavelength, flat-field/PRNU, and spectral-response/QE selections.
2. Validate compatibility with the active detector and processing context.
3. Activate accepted selections for subsequent processing.
4. Save or recall user settings and report the outcome.
5. Keep the current active configuration when a requested save, recall, or selection fails.

.. _uuid-6f8d090f-8f0a-407b-bda0-332a52334a3e:
