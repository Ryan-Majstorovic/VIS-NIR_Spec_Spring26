Display Update Flow
-------------------

UUID: :ref:`B27EBF8B-6D5F-41E6-B829-04A23785EFE0 <uuid-b27ebf8b-6d5f-41e6-b829-04a23785efe0>`

1. Accept only a qualified wavelength-and-intensity record.
2. Update the live intensity-versus-wavelength view from the current record.
3. Append accepted records to rolling spectrogram history when that view is enabled.
4. Update connection, device, and session indicators independently of spectrum rendering.
5. Identify stale or unavailable display data.
