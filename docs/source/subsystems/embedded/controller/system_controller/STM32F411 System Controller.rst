STM32F411 System Controller
===========================

Layer 3 secondary-system page for the STM32F411CEU6 acquisition controller.

The controller shall provide the embedded acquisition, timing, and USB
coordination needed by the instrument.  This page intentionally does not assign
registers, timer channels, pin numbers, or firmware state-machine mechanics;
those are implementation evidence for a later review.
