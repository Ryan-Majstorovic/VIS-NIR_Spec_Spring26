Timing Reference Inputs
=======================

UUID: ``78266345-6060-41B1-995E-76D7A96CF314``

Required inputs:

* the approved nominal timing requirements for fM, SH, ICG, SH pulse width, and
  the ADC trigger function;
* an instrument with a documented timebase suitable for the required timing
  checks;
* accessible driver-board or CCD-side timing observation points; and
* a record identifier for the hardware configuration and requirement revision
  under test.

Timer allocation, probe model, probe loading, capture duration, repetition
count, and evidence-retention rules are ``Not In Docs``.
