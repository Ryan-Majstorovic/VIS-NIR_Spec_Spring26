Timing Reference Procedure
==========================

UUID: ``91D8792D-AE7E-430D-ABCD-1999DB7D404F``

1. Identify the approved timing requirements and hardware configuration under
   test.
2. Connect the measurement instrument to the accessible fM, SH, ICG, and ADC
   trigger observation points.
3. Power the detector interface using the approved laboratory procedure.
4. Measure fM and assess frequency and stability against 2 MHz +/- 0.1%.
5. Trigger on ICG and capture SH plus the ADC trigger behavior during a complete
   frame.  Check that the 10 microsecond SH pulse aligns with ICG so the
   required ICG off time is preserved.
6. Compare measured periods, pulse widths, and SH/ICG alignment with the
   approved requirements.  Treat the capture application boundary as open
   until the shared control contract defines it.
7. Record pass/fail disposition, configuration identifiers, and links to the
   captured evidence.

Capture duration, repetition count, naming, retention, and exact acceptance
formula are ``Not In Docs`` and must be supplied by Test and Verification.
