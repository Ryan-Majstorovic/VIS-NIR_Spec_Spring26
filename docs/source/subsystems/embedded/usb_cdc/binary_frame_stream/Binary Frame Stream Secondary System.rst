Binary Frame Stream Secondary System
====================================

Layer 3 secondary-system page for the binary USB CDC measurement stream.

The stream shall carry complete frames produced by acquisition, together with
frame identity and status information sufficient for the receiver to detect
missing, incomplete, or faulted captures.  The packet name, field layout,
encoding, acknowledgments, and recovery behavior are defined by Integration.
