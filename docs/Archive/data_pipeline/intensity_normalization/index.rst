Intensity Normalization
=======================

UUID: ``I1N2T3S4-N5O6-7890-FLDA-TS1234567890``

The Intensity Normalization stage scales the fully corrected spectral signal (after bias subtraction, dark correction, bad pixel masking, wavelength mapping, PRNU/flat-field, and QE corrections) into a displayable 0-to-1 range. This page documents two normalization modes: per-frame auto-peak scaling and absolute saturation-referenced scaling that preserves cross-frame intensity comparisons.
