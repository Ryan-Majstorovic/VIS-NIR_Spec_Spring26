Dense HDF5 and CSV Export
=========================

UUID: ``H1D2F3G4-H5I6-7890-JKLM-NOPQRSTUVWX``

The Dense HDF5 and CSV Export stage persists fully processed spectral data to disk for offline analysis, archival, and sharing. This page documents the dense binary recording workflow (per-pixel time series in HDF5 format) and the frame-level CSV export path. It covers file formats, dataset layouts, metadata attributes, worker thread architecture, and cross-frame lookup mechanisms.
