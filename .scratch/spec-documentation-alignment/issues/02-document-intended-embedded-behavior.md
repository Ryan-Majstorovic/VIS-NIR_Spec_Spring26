# Document Intended Embedded Behavior

Type: task
Status: open
Blocked by: 01

## Question

What should the embedded spectrometer controller do, and how should that intended behavior be captured in the Sphinx documentation without relying on the current firmware implementation as the source of truth?

## Done When

- Intended embedded behavior is documented in the existing embedded documentation area.
- Acquisition, timing, calibration, and USB/host-interface behavior are covered at a level that supports later implementation checks.
- Open assumptions and unresolved hardware decisions are called out explicitly instead of being hidden in prose.
